1.1 業務背景與問題定義

在房地產市場交易中，房屋公允市場價格 (Fair Market Value) 的精準定價是房仲業、購屋者、房地產投資人及銀行抵押貸款核貸部門的關鍵核心。

  • 對金融機構而言：貸款成數 (Loan-to-Value, LTV) 與風險準備金評估需依據客觀透明的精算模型，避免房價估值泡沫引發次貸違約系統性風險。

本專案旨在透過華盛頓州 King County（包含西雅圖市）的實價登錄資料，建立一套高精準度且具備可解釋性的多元線性迴歸模型，並提供 95% 信賴區間 (Confidence Interval) 與 95% 預測區間 (Prediction Interval)，量化不同物理屬性、建築結構與地理區位對房價的邊際貢獻。

1.2 多元線性迴歸理論數學模型

多元線性迴歸假設目標變數 $y$ 與 $p$ 個自變數 $x_1, x_2, \dots, x_p$ 之間存在線性加法關係：

$$y_i = \beta_0 + \beta_1 x_{i1} + \beta_2 x_{i2} + \cdots + \beta_p x_{ip} + \varepsilon_i, \quad i = 1, 2, \dots, n$$

以矩陣形式表示：

$$\mathbf{y} = \mathbf{X} \boldsymbol{\beta} + \boldsymbol{\varepsilon}$$

其中：

  • $\mathbf{y} \in \mathbb{R}^{n \times 1}$ 為房屋成交價格向量。
  • $\mathbf{X} \in \mathbb{R}^{n \times (p+1)}$ 為設計矩陣 (Design Matrix)，第一行全為 1（截距項）。
  • $\boldsymbol{\beta} = [\beta_0, \beta_1, \dots, \beta_p]^T \in \mathbb{R}^{(p+1) \times 1}$ 為待估計之未知迴歸係數向量。
  • $\boldsymbol{\varepsilon} \in \mathbb{R}^{n \times 1}$ 為隨機誤差向量，滿足高斯-馬可夫基本假設： $$E(\boldsymbol{\varepsilon}) = \mathbf{0}, \quad \text{Var}(\boldsymbol{\varepsilon}) = \sigma^2 \mathbf{I}_n$$

最小平方法 (Ordinary Least Squares, OLS) 求解目標為最小化殘差平方和 (Residual Sum of Squares, RSS)：

$$\hat{\boldsymbol{\beta}} = \arg\min_{\boldsymbol{\beta}} \sum_{i=1}^n (y_i - \mathbf{x}_i^T \boldsymbol{\beta})^2 = (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \mathbf{y}$$

三、Phase 3: 資料準備與特徵工程 (Data Preparation)

3.1 完全線性共線性 (Exact Collinearity) 處理

在多元線性迴歸中，若特徵之間存在完全線性組合，設計矩陣 $\mathbf{X}$ 將發生秩虧 (Rank Deficiency)，導致 $\mathbf{X}^T \mathbf{X}$ 不可逆（行列式 $\det(\mathbf{X}^T \mathbf{X}) = 0$）：

$$\det(\mathbf{X}^T \mathbf{X}) = 0 \implies (\mathbf{X}^T \mathbf{X})^{-1} \text{ 不存在}$$

實證檢驗 King County 資料集時發現： $$\text{sqft\_living} = \text{sqft\_above} + \text{sqft\_basement}$$ 全樣本中兩者差值最大值精確為 $0$！此即典型的完全共線性。若同時納入將引發矩陣奇異警告 (SingularMatrixWarning)。 處理對策：排除 sqft_basement，保留主特徵 sqft_living 與 sqft_above，使自變數矩陣恢復滿秩條件。

3.2 資料集切分與特徵標準化

  1. 資料集切分：將 21,613 筆資料依照 80% 訓練集 (17,290 筆) 與 20% 測試集 (4,323 筆) 切分，設定隨機種子 random_state = 42。
  2. 特徵標準化 (Z-score Standardization)： 為了使不同量綱（平方英尺、年份、緯度等）能在正則化模型中受到對等懲罰，並使標準化係數可直接比較重要性，對自變數執行標準化轉換：

$$z_{ij} = \frac{x_{ij} - \bar{x}_j}{s_j}, \quad \text{其中 } \bar{x}_j = \frac{1}{n} \sum_{i=1}^n x_{ij}, \quad s_j = \sqrt{\frac{1}{n-1} \sum_{i=1}^n (x_{ij} - \bar{x}_j)^2}$$

四、Phase 4: 模型建立與特徵選擇 (Modeling & Feature Selection)

4.1 模型建立理論與數學損失函數

1. 全特徵多元線性迴歸 (Baseline OLS)

最小化無約束殘差平方和：

$$\min_{\boldsymbol{\beta}} \sum_{i=1}^n (y_i - \mathbf{x}_i^T \boldsymbol{\beta})^2$$

2. 特徵選擇 (Feature Selection via RFE)

採用遞迴特徵消除法 (Recursive Feature Elimination, RFE)，以線性迴歸權重為基準，透過迭代修剪係數絕對值最小且對整體 $RSS$ 貢獻最低的特徵，精選出最具預測效能的 12 個核心特徵： $$\text{Selected Features} = \{\text{bedrooms}, \text{bathrooms}, \text{sqft\_living}, \text{waterfront}, \text{view}, \text{condition}, \text{grade}, \text{sqft\_above}, \text{yr\_built}, \text{zipcode}, \text{lat}, \text{long}\}$$

3. 嶺迴歸 (Ridge Regression, L2 Regularization)

加入 L2 懲罰項，平滑迴歸係數：

$$\min_{\boldsymbol{\beta}} \left\{ \sum_{i=1}^n (y_i - \mathbf{x}_i^T \boldsymbol{\beta})^2 + \lambda \sum_{j=1}^p \beta_j^2 \right\} \implies \hat{\boldsymbol{\beta}}_{\text{Ridge}} = (\mathbf{X}^T \mathbf{X} + \lambda \mathbf{I})^{-1} \mathbf{X}^T \mathbf{y}$$

超參數設定 $\lambda = 10.0$。

4. 套索迴歸 (Lasso Regression, L1 Regularization)

加入 L1 懲罰項，因其在座標軸上的稜角幾何特性，可將次要特徵係數嚴格壓縮至 0，達成自動化特徵選擇 (Feature Selection)：

$$\min_{\boldsymbol{\beta}} \left\{ \sum_{i=1}^n (y_i - \mathbf{x}_i^T \boldsymbol{\beta})^2 + \lambda \sum_{j=1}^p |\beta_j| \right\}$$

超參數設定 $\lambda = 100.0$。

5. 彈性網絡迴歸 (ElasticNet Regression)

融合 L1 與 L2 懲罰項：

$$\min_{\boldsymbol{\beta}} \left\{ \sum_{i=1}^n (y_i - \mathbf{x}_i^T \boldsymbol{\beta})^2 + \lambda \left( \alpha \sum_{j=1}^p |\beta_j| + \frac{1-\alpha}{2} \sum_{j=1}^p \beta_j^2 \right) \right\}$$

超參數設定 $\lambda = 0.1, \alpha = 0.5$。

五、Phase 5: 模型評估與推論 (Evaluation & Prediction Intervals)

5.1 評估指標之數學定義

  • 均方根誤差 (Root Mean Squared Error, RMSE)： $$\text{RMSE} = \sqrt{\frac{1}{n} \sum_{i=1}^n (y_i - \hat{y}_i)^2}$$
  • 平均絕對誤差 (Mean Absolute Error, MAE)： $$\text{MAE} = \frac{1}{n} \sum_{i=1}^n |y_i - \hat{y}_i|$$
  • 決定係數 ($R^2$)： $$R^2 = 1 - \frac{\sum_{i=1}^n (y_i - \hat{y}_i)^2}{\sum_{i=1}^n (y_i - \bar{y})^2}$$
  • 調整後決定係數 (Adjusted $R^2$)： $$R^2_{\text{adj}} = 1 - (1 - R^2) \frac{n - 1}{n - p - 1}$$

5.4 ⭐ 預測圖：95% 信賴區間與 95% 預測區間推導與實證

數學理論推導

對於給定一組新的房屋特徵向量 $\mathbf{x}_0 = [1, x_{01}, x_{02}, \dots, x_{0p}]^T$：

  1. 點預測值 (Point Estimate)： $$\hat{y}_0 = \mathbf{x}_0^T \hat{\boldsymbol{\beta}}$$

  2. 95% 信賴區間 (Confidence Interval for Mean Response $E(y_0)$)： 代表在特徵為 $\mathbf{x}_0$ 下，全體房屋平均市場價格所在的 95% 信賴界限： $$\text{Var}(\hat{y}_0) = s_e^2 \cdot \mathbf{x}_0^T (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{x}_0$$ $$\text{CI}_{1-\alpha} = \hat{y}_0 \pm t_{\alpha/2, \, n-p-1} \cdot s_e \sqrt{\mathbf{x}_0^T (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{x}_0}$$

  3. 95% 預測區間 (Prediction Interval for Individual Observation $y_0$)： 代表未來某一特定單一房屋實際成交價格所在之 95% 容許區間。由於除了估計誤差外，還包含不可避免的個別隨機誤差 $\varepsilon_0$（其變異數為 $\sigma^2$）： $$\text{Var}(y_0 - \hat{y}_0) = \text{Var}(\varepsilon_0) + \text{Var}(\hat{y}_0) = s_e^2 \left( 1 + \mathbf{x}_0^T (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{x}_0 \right)$$ $$\text{PI}_{1-\alpha} = \hat{y}_0 \pm t_{\alpha/2, \, n-p-1} \cdot s_e \sqrt{1 + \mathbf{x}_0^T (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{x}_0}$$

實證預測圖解讀 (如圖 6)

  • 深藍色線為迴歸模型點預測值 $\hat{y}$。
  • 藍色帶狀區域為 95% 信賴區間：由於樣本量充沛 ($n=17,290$)，均值估計精確度極高，帶狀區間窄而穩定。
  • 紅色寬闊帶狀區域為 95% 預測區間：精準包覆了絕大多數測試集實際紅點樣本（覆蓋率高達 95.2%），客觀體現了房市個別買賣議價與未觀測裝潢等特異性波動空間。

六、Phase 6: 模型部署與應用規劃 (Deployment)

6.1 線上房價估價 API 微服務架構

  1. 模型序列化：將經由 RFE 篩選之 12 個核心特徵係數矩陣 $\hat{\boldsymbol{\beta}}$ 與標準化轉換器以 joblib 序列化保存。
  2. RESTful API 服務： 使用 FastAPI 開發房價預估端點 /api/v1/predict-price，輸入房屋 12 項規格，即時回傳：
    • 推薦市場成交價 $\hat{y}_0$
    • 95% 信賴區間（合理均價開價建議區間）
    • 95% 預測區間（市場異常波動容忍界線）
  3. MLOps 持續維護排程： 透過 Apache Airflow 每月定期抓取 King County 實價登錄更新資料，觸發自動化重訓與漂移檢測 (Data Drift Detection)。
