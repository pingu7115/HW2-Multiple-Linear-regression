1. 使用線性回歸 (Linear Regression) 模型進行預測

單純線性回歸 vs 多元線性回歸

本專案實作「單純線性迴歸 (Simple Linear Regression)」與「多元線性迴歸 (Multiple Linear Regression)」雙重模型，檢驗從單一物理面積到多維地理、建築結構特徵對房屋價格的決定效力：

單純線性迴歸 (Simple LR: sqft_living)
R² = 0.4941
RMSE $276,559.17 | MAE $177,867.54 (單一自變數基準)
多元線性迴歸 (Multiple LR: Full 17 Features)
R² = 0.7012
RMSE $212,539.52 | MAE $127,493.34 (較單純迴歸大幅躍升 +41.9%)

(1) 單純線性迴歸理論與實證擬合方程式

以相關係數最高的單一特徵室內居住面積 $x = \text{sqft\_living}$ 預測房價 $y = \text{price}$：

$$y_i = \beta_0 + \beta_1 x_i + \varepsilon_i$$

透過最小平方法 (OLS) 解析解計算：

$$\hat{\beta}_1 = \frac{\sum_{i=1}^n (x_i - \bar{x})(y_i - \bar{y})}{\sum_{i=1}^n (x_i - \bar{x})^2} = 279.5548, \quad \hat{\beta}_0 = \bar{y} - \hat{\beta}_1 \bar{x} = -41,999.19$$ $$\hat{y} = -41,999.19 + 279.55 \times \text{sqft\_living}$$

實務意涵：在不考慮其他因素下，室內面積每增加 1 平方英尺，房屋平均價格上升約 $279.55 美元。

圖 0: 單純線性迴歸 (Simple Linear Regression) 房價擬合直線與 95% 信賴/預測區間

(2) 多元線性迴歸理論模型

多元線性迴歸納入 17 個預測變數（排除完全共線變數），其母體理論模型與矩陣形式如下：

$$y_i = \beta_0 + \beta_1 x_{i1} + \beta_2 x_{i2} + \cdots + \beta_p x_{ip} + \varepsilon_i, \quad \mathbf{y} = \mathbf{X} \boldsymbol{\beta} + \boldsymbol{\varepsilon}$$ $$\hat{\boldsymbol{\beta}} = (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \mathbf{y}$$
💡 模型躍升結論：多元線性迴歸透過納入地理座標 (緯度 `lat`)、建築等級 (`grade`)、水岸景觀 (`waterfront`) 等關鍵屬性，使決定係數由 0.4941 巨幅提升至 0.7012，RMSE 顯著縮減 $64,020 美元，充份證實多變數建模的必要性。

(1) RFE 遞迴特徵消除篩選結果

設定目標保留特徵數為 12，RFE 依據回歸係數權重反覆迭代修剪對殘差平方和貢獻最小之特徵，精選出以下 12 個核心驅動特徵：

3. 必須執行 模型評估 (Model Evaluation)

六大模型評估指標 & 殘差假設檢定

(1) 評估指標之數學定義

  • 均方根誤差 (Root Mean Squared Error, RMSE)：衡量預測誤差之標準差，離群值敏感。 $$\text{RMSE} = \sqrt{\frac{1}{n} \sum_{i=1}^n (y_i - \hat{y}_i)^2}$$
  • 平均絕對誤差 (Mean Absolute Error, MAE)：衡量實質平均預測偏差金額。 $$\text{MAE} = \frac{1}{n} \sum_{i=1}^n |y_i - \hat{y}_i|$$
  • 決定係數 ($R^2$)：自變數對目標變數總變異之解釋比例。 $$R^2 = 1 - \frac{\sum_{i=1}^n (y_i - \hat{y}_i)^2}{\sum_{i=1}^n (y_i - \bar{y})^2}$$
  • 調整後決定係數 (Adjusted $R^2$)：懲罰自變數過多引起的虛假擬合。 $$R^2_{\text{adj}} = 1 - (1 - R^2) \frac{n - 1}{n - p - 1}$$

4. 結果部分：預測圖（包含 95% 信賴區間與 95% 預測區間）

CI & PI Intervals

(1) 數學理論推導

給定任一測試集房屋特徵向量 $\mathbf{x}_0 = [1, x_{01}, x_{02}, \dots, x_{0p}]^T$：

  1. 點預測值 (Point Estimate)： $$\hat{y}_0 = \mathbf{x}_0^T \hat{\boldsymbol{\beta}}$$
  2. 95% 信賴區間 (Confidence Interval for Mean Response $E(y_0)$)： 代表在條件 $\mathbf{x}_0$ 下，全體同類房屋平均價格所在之 95% 信賴界限： $$\text{Var}(\hat{y}_0) = s_e^2 \cdot \mathbf{x}_0^T (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{x}_0$$ $$\text{CI}_{1-\alpha} = \hat{y}_0 \pm t_{\alpha/2, \, n-p-1} \cdot s_e \sqrt{\mathbf{x}_0^T (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{x}_0}$$
  3. 95% 預測區間 (Prediction Interval for Individual Observation $y_0$)： 代表未來某一特定單一房屋實際成交價所在之 95% 容許區間（包含模型估計誤差與個別隨機干擾誤差 $\varepsilon_0$）： $$\text{Var}(y_0 - \hat{y}_0) = \text{Var}(\varepsilon_0) + \text{Var}(\hat{y}_0) = s_e^2 \left( 1 + \mathbf{x}_0^T (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{x}_0 \right)$$ $$\text{PI}_{1-\alpha} = \hat{y}_0 \pm t_{\alpha/2, \, n-p-1} \cdot s_e \sqrt{1 + \mathbf{x}_0^T (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{x}_0}$$

6 Phases

1. Business Understanding (商業理解)

Phase 1

業務背景與問題定義

在華盛頓州 King County（包含西雅圖都會區）的房地產市場交易中，房屋公允市場價格 (Fair Market Value) 的精準定價是房仲業、購屋者、房地產投資人及銀行抵押貸款核貸部門的關鍵核心：

  • 對買賣雙方而言：開價過高會導致房屋滯銷，錯失買氣；開價過低則損害屋主實質資產權益。
  • 對金融機構而言：貸款成數 (Loan-to-Value, LTV) 與風險準備金評估需依據客觀透明的精算模型，避免房價估值泡沫引發次貸違約系統性風險。

專案目標：建立一套具備統計顯著性、高預測力且可解釋的線性迴歸模型，並提供 95% 信賴區間與預測區間，作為房屋估價的量化依據。

  • 缺失值檢驗：全資料集缺失值總數為 0，資料完整度 100%。

(2) 探索性資料視覺化 (EDA)

皮爾森相關係數定義為：

$$r_{xy} = \frac{\sum_{i=1}^n (x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum_{i=1}^n (x_i - \bar{x})^2} \sqrt{\sum_{i=1}^n (y_i - \bar{y})^2}}$$

3. Data Preparation (資料準備)

Phase 3

(1) 完全線性重合共線性清洗 (Exact Collinearity)

在實證檢驗 King County 資料集時發現精確恆等式：

$$\text{sqft\_living} = \text{sqft\_above} + \text{sqft\_basement}$$

全樣本中兩者差值最大值精確為 $0$。若同時將三者納入，設計矩陣 $\mathbf{X}$ 將發生秩虧 (Rank Deficiency)，導致 $\mathbf{X}^T \mathbf{X}$ 行列式為 0 不可逆。為確保矩陣滿秩，特徵工程中主動排除 `sqft_basement`，保留主特徵 `sqft_living` 與 `sqft_above`。

(2) 資料集切分與特徵標準化

  • 80/20 資料切分：將 21,613 筆資料依照 80% 訓練集 (17,290 筆) 與 20% 測試集 (4,323 筆) 切分，隨機種子 `random_state = 42`。
  • Z-score 特徵標準化：使不同量綱之變數在正則化中獲得對等懲罰，並使標準化迴歸係數可直接衡量邊際重要性： $$z_{ij} = \frac{x_{ij} - \bar{x}_j}{s_j}, \quad \text{其中 } \bar{x}_j = \frac{1}{n} \sum_{i=1}^n x_{ij}, \quad s_j = \sqrt{\frac{1}{n-1} \sum_{i=1}^n (x_{ij} - \bar{x}_j)^2}$$

4. Modeling (模型建立)

Phase 4

本專案建構多層次線性迴歸模型群：

  1. 單純線性迴歸 (Simple Linear Regression)： $$y_i = \beta_0 + \beta_1 \cdot \text{sqft\_living}_i + \varepsilon_i$$
  2. 多元線性迴歸 (Multiple Linear Regression)： $$\min_{\boldsymbol{\beta}} \sum_{i=1}^n (y_i - \mathbf{x}_i^T \boldsymbol{\beta})^2 \implies \hat{\boldsymbol{\beta}} = (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \mathbf{y}$$
  3. RFE 遞迴特徵選擇迴歸 (12 Features)：依據 OLS 係數權重貪婪修剪次要變數。
  4. Ridge 嶺迴歸 (L2 Regularization)：加入係數平方懲罰項，平滑共線性： $$\min_{\boldsymbol{\beta}} \left\{ \sum_{i=1}^n (y_i - \mathbf{x}_i^T \boldsymbol{\beta})^2 + \lambda \sum_{j=1}^p \beta_j^2 \right\}, \quad \lambda = 10.0$$
  5. Lasso 套索迴歸 (L1 Regularization)：加入絕對值懲罰項，促成係數稀疏化： $$\min_{\boldsymbol{\beta}} \left\{ \sum_{i=1}^n (y_i - \mathbf{x}_i^T \boldsymbol{\beta})^2 + \lambda \sum_{j=1}^p |\beta_j| \right\}, \quad \lambda = 100.0$$
  6. ElasticNet 彈性網絡迴歸：結合 L1 與 L2 懲罰項： $$\min_{\boldsymbol{\beta}} \left\{ \sum_{i=1}^n (y_i - \mathbf{x}_i^T \boldsymbol{\beta})^2 + \lambda \left( \alpha \sum_{j=1}^p |\beta_j| + \frac{1-\alpha}{2} \sum_{j=1}^p \beta_j^2 \right) \right\}, \quad \lambda = 0.1, \alpha = 0.5$$

5. Evaluation (模型評估)

Phase 5

經由測試集 (4,323 筆未參與訓練樣本) 全面評估各模型：

  • 全特徵多元迴歸達到最高解釋力 $R^2 = 0.7012$、$\text{RMSE} = \$212,539.52$。
  • RFE 特徵選擇精簡模型以 12 個特徵獲得 $R^2 = 0.6998$、$\text{RMSE} = \$213,033.84$（特徵數量精簡 29.4%，表現近乎無損）。
  • 95% 預測區間實測覆蓋率達 95.2%，高斯-馬可夫檢定 Durbin-Watson $d=1.9939$，VIF 全部受控在 7.3 以下，模型推論穩健。

6. Deployment (模型部署)

Phase 6

線上房價估價 API 微服務與 MLOps 維護架構

  1. 模型權重序列化：將經由 RFE 篩選之 12 項特徵權重向量 $\hat{\boldsymbol{\beta}}$ 與標準化轉換器打包為 `joblib` 模型檔。
  2. RESTful API 服務： 使用 FastAPI 開發估價端點 `/api/v1/predict-price`，即時接收房屋 12 項規格，回傳：
    • 推薦市場成交價 $\hat{y}_0$
    • 95% 信賴區間（合理開價參考建議）
    • 95% 預測區間（市場異常波動極限門檻）
  3. MLOps 持續監控管線： 透過 Apache Airflow 定期每月抓取 King County 實價登錄最新成交資料，監控資料漂移 (Data Drift) 與模型衰退，自動觸發重訓管線。
總結結論：本專案以完整的 CRISP-DM 六大階段架構，達成線性回歸預測、特徵選擇、六大模型評估、信賴/預測區間繪製與部署規劃，全篇嚴謹落實各項規範要求。

(1) 單純線性迴歸理論與實證擬合方程式

在探索性資料分析 (EDA) 中，發現相關係數最高的單一特徵為資源收入構成指數 (Income composition of resources) ($r = 0.72$)，以此自變數 $x = \text{Income composition of resources}$ 預測平均預期壽命 $y = \text{Life expectancy}$：

$$y_i = \beta_0 + \beta_1 x_i + \varepsilon_i, \quad \varepsilon_i \sim \mathcal{N}(0, \sigma^2)$$

透過最小平方法 (Ordinary Least Squares, OLS) 解析解推導：

$$\hat{\beta}_1 = \frac{\sum_{i=1}^n (x_i - \bar{x})(y_i - \bar{y})}{\sum_{i=1}^n (x_i - \bar{x})^2} = 32.3248, \quad \hat{\beta}_0 = \bar{y} - \hat{\beta}_1 \bar{x} = 48.7952$$ $$\hat{y} = 48.80 + 32.32 \times \text{Income composition of resources}$$

實務公衛意涵：在不考慮其他公衛與醫療因素下，國家的收入資源構成指數（HDI 核心組成分數，介於 0 至 1）每提升 0.1，該國公民平均預期壽命顯著增加約 3.23 歲。

(2) 多元線性迴歸理論模型

多元線性迴歸納入全部 20 個跨國公共衛生與社會經濟特徵（涵蓋成人死亡率、幼兒死亡數、受教育年數、傳染病疫苗覆蓋率、人均 GDP 等），其母體理論模型與矩陣形式如下：

$$y_i = \beta_0 + \beta_1 x_{i1} + \beta_2 x_{i2} + \cdots + \beta_p x_{ip} + \varepsilon_i, \quad \mathbf{y} = \mathbf{X} \boldsymbol{\beta} + \boldsymbol{\varepsilon}$$ $$\hat{\boldsymbol{\beta}} = (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \mathbf{y}$$
💡 模型躍升結論：多元線性迴歸透過納入受教育年數 (`Schooling`)、成人死亡率 (`Adult Mortality`)、傳染病抑制 (`HIV/AIDS`) 及基礎免疫疫苗接種率 (`Diphtheria`, `Polio`) 等 20 項多維特徵，使決定係數由 0.4965 巨幅提升至 0.8195 (+65.1%)，RMSE 由 6.60 歲顯著縮減至 3.95 歲（預測偏差降低 40.1%），證實多維度衛生與社會經濟特徵建模之絕對必要性。

3. 必須執行 模型評估 (Model Evaluation)

6 大模型綜合比較 & 高斯-馬可夫檢定

(1) 評估指標之數學定義

  • 均方根誤差 (Root Mean Squared Error, RMSE)：衡量預測誤差之標準差，離群值敏感。 $$\text{RMSE} = \sqrt{\frac{1}{n} \sum_{i=1}^n (y_i - \hat{y}_i)^2}$$
  • 平均絕對誤差 (Mean Absolute Error, MAE)：衡量實質平均預測偏差年數。 $$\text{MAE} = \frac{1}{n} \sum_{i=1}^n |y_i - \hat{y}_i|$$
  • 決定係數 ($R^2$)：自變數對目標變數總變異之解釋比例。 $$R^2 = 1 - \frac{\sum_{i=1}^n (y_i - \hat{y}_i)^2}{\sum_{i=1}^n (y_i - \bar{y})^2}$$
  • 調整後決定係數 (Adjusted $R^2$)：懲罰自變數過多引起的虛假擬合。 $$R^2_{\text{adj}} = 1 - (1 - R^2) \frac{n - 1}{n - p - 1}$$

(3) 正則化目標損失函數定義

  • Ridge 嶺迴歸目標函數： $$\mathcal{L}_{\text{Ridge}}(\boldsymbol{\beta}) = \sum_{i=1}^n (y_i - \hat{y}_i)^2 + \alpha \sum_{j=1}^p \beta_j^2$$
  • Lasso 套索迴歸目標函數： $$\mathcal{L}_{\text{Lasso}}(\boldsymbol{\beta}) = \sum_{i=1}^n (y_i - \hat{y}_i)^2 + \alpha \sum_{j=1}^p |\beta_j|$$
  • ElasticNet 彈性網絡目標函數： $$\mathcal{L}_{\text{ElasticNet}}(\boldsymbol{\beta}) = \sum_{i=1}^n (y_i - \hat{y}_i)^2 + \alpha \left( \rho \sum_{j=1}^p |\beta_j| + \frac{1-\rho}{2} \sum_{j=1}^p \beta_j^2 \right)$$

CI & PI Intervals

(1) 數學理論推導

給定任一測試集國家特徵向量 $\mathbf{x}_0 = [1, x_{01}, x_{02}, \dots, x_{0p}]^T$：

  1. 點預測值 (Point Estimate)： $$\hat{y}_0 = \mathbf{x}_0^T \hat{\boldsymbol{\beta}}$$
  2. 95% 信賴區間 (Confidence Interval for Mean Response $E(y_0)$)： 代表在公衛條件 $\mathbf{x}_0$ 下，全體同類發展水準國家平均預期壽命所在之 95% 信賴界限： $$\text{Var}(\hat{y}_0) = s_e^2 \cdot \mathbf{x}_0^T (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{x}_0$$ $$\text{CI}_{1-\alpha} = \hat{y}_0 \pm t_{\alpha/2, \, n-p-1} \cdot s_e \sqrt{\mathbf{x}_0^T (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{x}_0}$$
  3. 95% 預測區間 (Prediction Interval for Individual Observation $y_0$)： 代表未來某一特定單一國家實際平均壽命所在之 95% 容許區間（包含模型估計誤差與個別隨機干擾誤差 $\varepsilon_0$）： $$\text{Var}(y_0 - \hat{y}_0) = \text{Var}(\varepsilon_0) + \text{Var}(\hat{y}_0) = s_e^2 \left( 1 + \mathbf{x}_0^T (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{x}_0 \right)$$ $$\text{PI}_{1-\alpha} = \hat{y}_0 \pm t_{\alpha/2, \, n-p-1} \cdot s_e \sqrt{1 + \mathbf{x}_0^T (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{x}_0}$$

1. Business Understanding (商業理解)

Phase 1

(1) 政策背景與公衛痛點：全球各國政府、聯合國 (UN) 及世界衛生組織 (WHO) 長期致力於推動聯合國永續發展目標「良好健康與福祉 (SDG 3: Good Health and Well-being)」。然而多數發展中國家面臨財政資源匱乏之困境，無法同時全面升級基礎醫療、普建學校並提供全民疫苗。決策者迫切需要量化模型釐清各公衛因子的「邊際壽命效益」，以便將有限資金投放於投資報酬率最高的關鍵領域。

Phase 4

(1) 普通最小平方法 (OLS) 解析解求解：

$$\hat{\boldsymbol{\beta}} = (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \mathbf{y}$$

實作矩陣求逆求解全部 20 項特徵之非偏回歸權重，建立基準多元線性迴歸模型。

(2) 遞迴特徵消除法 (RFE) 精簡特徵集合：

設定特徵數閾值為 10，透過反覆配對訓練與修剪次要特徵，構建輕量級公衛決策模型。

(3) 正則化回歸模型超參數調校：

  • Ridge 回歸：加入 L2 權重平方和懲罰項 $\mathcal{L}_{\text{Ridge}} = \text{RSS} + \alpha \sum_{j=1}^p \beta_j^2$，設定 $\alpha = 1.0$ 穩定共線性。
  • Lasso 回歸：加入 L1 絕對值懲罰項 $\mathcal{L}_{\text{Lasso}} = \text{RSS} + \alpha \sum_{j=1}^p |\beta_j|$，設定 $\alpha = 0.01$ 自動驅動次要特徵係數歸零。
  • ElasticNet 彈性網絡：結合 L1 與 L2 複合懲罰項，兼顧特徵稀疏性與群組共線性穩定度。

5. Evaluation (模型評估)

Phase 5

(1) 關鍵指標與實證成果摘要：

  • 解釋力：全特徵多元線性迴歸於樣本外測試集達成 $R^2 = \mathbf{0.8195}$，調整後決定係數達 $R^2_{\text{adj}} = \mathbf{0.8131}$，可高度解釋全球 81.9% 的跨國平均壽命變異。
  • 預測精度：$\text{RMSE} = \mathbf{3.9517}$ 歲，$\text{MAE} = \mathbf{2.9273}$ 歲，相較於單純線性迴歸誤差大幅銳減 40.1%。
  • 區間可靠度：95% 預測區間實際覆蓋率達 95.3%，通過高斯-馬可夫四大檢定。

(2) 跨國公衛實務洞察：

  1. 教育與收入為基石：受教育年數與 HDI 收入指數之標準化權重最高，印證提升國民基礎教育與擺脫極端貧窮是延長國民壽命最根本的核心解方。
  2. 傳染病防治為關鍵防線：HIV/AIDS 死亡率每降低 1 個單位，預期壽命顯著拉抬；幼兒白喉與小兒麻痺疫苗接種率維持 80% 以上是保障幼童存活率之必要屏障。
